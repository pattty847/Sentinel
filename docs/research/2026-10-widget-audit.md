**Highest-severity findings**

1. **P1 — Limit-ticket intent is overwritten.** Every new trade updates the limit spinbox whenever it lacks focus (`PaperTradingDock.cpp:478`). A trader can type a limit, move to quantity or a button, and have the next tick replace it. Algorithm status also becomes RUNNING immediately after sending, while the incoming algo event handler is empty (`:568`, `:617`). Preserve user-entered prices and derive execution state from acknowledgements.
2. **P1 — DOM conveys ambiguous and sometimes duplicated data.** BUYS/SELLS/DELTA count the last 1,000 executions, not traded size or a stated time window. The ask loop includes the best ask, then the midpoint row can include it again (`OrderBookDock.cpp:291–319`). In the actual API sample, best bid and ask both occupied the $84,803.8 bucket and spread was zero at the $0.10 book tick; this is bucket resolution, not proof of a zero exchange spread. Make the ladder unique by price and disclose aggregation and count basis.
3. **P1 — Toolbar exposes controls without behaviour.** `chartTypeSelected`, `indicatorsRequested`, `layoutsRequested`, `quickSearchRequested`, and `fullscreenToggled` are emitted in `TopToolbar.cpp:157,276–279` but have no receivers in the searched GUI source. Candle/Hollow/Line and those action icons promise results they do not deliver. Connect supported actions or delete the controls; do not preserve decorative buttons.
4. **P1 — Secondary views can mislabel old data.** Stock ticker changes update the header without clearing old candles; failed refresh status is only visible when candle count is zero (`StockChartDock.cpp:146–173,260`, `qml/StockChartView.qml:409–412`). SEC symbol changes similarly replace the ticker without clearing or identifying the existing result set (`SecFilingDock.cpp:200`). Bind displayed results to their own symbol/request and show loading/error over retained data.
5. **P2 — No shared visual or freshness contract.** QWidget theme grays, QML blue-grays, neon commentary, material red/green DOM colours, hard-coded Roboto Mono/Menlo, and 9–16 px local styles coexist. Most market panels lack disconnected/stale/loading distinctions. Use GUI-owned tokens and semantic states; do not alter core's Qt boundary or the GPU hot path to accomplish this.
